# 用户与节点运维手册覆盖复核

日期：2026-09-14。本文供文档维护者跟踪覆盖范围；外部使用者入口为[用户与节点运维手册](../handbook/README.md)。

## 复核范围与依据

复核已提交的首批手册（`74e5e6d`），重点检查“节点启动 → 持续出块 → SourceDAO 初始化 → 导出与验证 → 日常维护”的操作是否连贯。

SourceDAO 和挖矿命令与公开 r25 node-kit 中的 `usdb_sourcedao.py`、`usdb_mining.py` 对照；这两个文件与本次工作区对应文件逐字节一致。SourceDAO 链上预检另核对 r25 固定的工具源码版本。操作说明采用已有工具，不增加人工拼接 RPC、镜像或部署参数的流程。

本轮只修改文档。命令参数和文档链接核对不等于实际链上初始化、完整同步或恢复演练通过；公开安装版本的既有问题仍以[测试网版本页](../handbook/networks/testnet.md)为准。

本轮静态核对通过：9 篇手册及相关导航/复核文件中的 127 处本地链接与章节锚点、57 个 Bash 代码块语法、46 种完整 CLI 命令参数；参数解析使用公开 r25 工具包，不执行节点命令。未启动容器、使用签名密钥或发送链上交易。

## 本轮补齐

| 原缺口 | 本轮处理 |
| --- | --- |
| 网络开始出块后没有独立 SourceDAO 章节 | 新增[初始化与验证](../handbook/network-admin/sourcedao.md)，包括 check、bootstrap、status、export、validate |
| 初始化依赖持续出块，但没有可用矿工手册 | 新增[CPU 挖矿](../handbook/node/mining.md)，区分加入矿工与首矿工，并说明本地产块证据 |
| 节点 READY 容易被当作网络初始化完成 | 在[状态页](../handbook/node/status.md#节点就绪后的独立检查)增加矿工、DAO 和普通加入节点的独立检查 |
| 停机/升级没有提前解释 SourceDAO 任务互斥 | 在[维护页](../handbook/node/maintenance.md#停止与重新启动)明确任务期间的限制和恢复入口 |
| 普通停机与持久停矿容易混淆 | 说明 down 保留角色、mining disable 持久回到 full |
| 备份说明未突出私有部署恢复记录 | 说明 state/journal 配套备份，公开导出和验证报告不能替代恢复材料 |
| 只有查看命令，缺少无人值守观察重点 | 增加基础[告警观察项](../handbook/node/maintenance.md#持续观察与告警)，不把正常等待等同故障 |
| 故障目录缺少矿工、初始化和操作互斥 | 增加症状导航与脱敏求助字段，具体处理只在对应专篇维护 |

## 仍需持续补充

| 优先级 | 缺口 | 现有基础与下一步 |
| --- | --- | --- |
| 高 | 可推荐的新节点安装版本与接入资料 | r25 首次配置问题、公开 Seed 和公共服务地址仍需实际版本/网络运维确认；取得材料后更新版本页，不能仅以源码修复代替可部署版本 |
| 高 | 首节点从空白主机到对外提供 Seed 的完整路径 | 已有首矿工和 DAO 步骤；仍需独立 `network-admin/first-node.md`，覆盖无 Seed 配置、启动等待、初始化验收和首个加入节点的核对 |
| 高 | Seed、IPv4/IPv6、NAT 和端口变更专篇 | [入网说明](usdb-node-peer-discovery-plan.md)、[IPv6 说明](usdb-node-ipv6-operations.md)及[防火墙说明](usdb-node-firewall-operations.md)已有实现依据；应整理成面向用户的 `node/networking.md`，包含公布地址、修改影响、实际连接和故障恢复 |
| 中 | 查询节点与 Explorer 配套部署 | 以[查询节点说明](usdb-node-query-mode.md)为基础整理 `node/query-node.md`，明确首次同步前的 archive/tracing 选择、历史覆盖和同机资源；Explorer 生命周期链接到独立工程 |
| 中 | 完整备份恢复、换盘、迁机和版本回退演练 | 当前仅说明边界；需按实际版本完成一致备份、恢复后的节点身份/数据/链检查，才提供可复制的恢复流程。内部 node1 定制清理脚本不能作为外部通用恢复方案 |
| 中 | 长期监控和日志留存 | 当前已补观察项；后续补监控接入样例、告警窗口、联系人、容器/文件日志分别保留及磁盘增长观察。阈值需要实际运行数据 |
| 中 | 网络事故和重置后的节点重新加入 | [深重组操作](usdb-testnet-v0-deep-btc-reorg-operations.md)侧重整网协调；外部手册仍需节点侧停写、保留证据、识别通知及新网络部署步骤，不开放任意解除停链命令 |
| 中 | 版本手册的交付入口 | 当前已有仓库和旧文档导航；后续让 Release 说明、安装完成提示指向匹配版本的手册，并评估随 node-kit 提供离线副本 |

建议下一批先整理首节点完整路径和网络配置专篇，再整理查询节点、恢复演练及长期监控。对外手册只展示已经具备的操作；计划、实现细节和验证待办继续留在本目录。

# USDB 用户与节点运维手册

这份手册帮助使用者安装 USDB 节点、加入测试网、观察同步、维护服务和排查故障。操作以发布包提供的 `usdb-node` 命令为入口，不需要下载源码或编译程序。

**首次部署前，请先查看[测试网版本与接入资料](networks/testnet.md)。** 2026-09-14 核对的公开版本 r25 存在首次配置问题，当前没有在本手册中确认可推荐的新节点安装版本。已有节点可按对应章节查询状态和维护。

新节点按“测试网资料 → 环境准备 → 安装与入网 → 状态确认”的顺序阅读。发生故障时，可以直接从现象进入故障排查。

网络初始化负责人在链启动后，按“启用首个矿工 → 确认持续出块 → SourceDAO 初始化 → 导出与验证”的顺序完成网络初始化。普通加入节点无需重复这些操作。

## 选择自己的使用方式

- **普通使用者**：通过网络运维方提供的浏览器和公共 RPC 使用测试网，不必自建节点。接入资料只列出已确认的信息；没有列出地址时，请向网络运维方获取。
- **节点运维人员**：本批手册默认部署 `full` 节点，同步并验证已有网络，不自动启用挖矿。
- **矿工**：先完成普通节点部署和入网，再按[CPU 挖矿](node/mining.md)检查资格、启停和确认产块。
- **网络初始化负责人**：链开始出块后按[SourceDAO 初始化与验证](network-admin/sourcedao.md)操作。普通加入节点不执行 `--first-node`，也不重复初始化 SourceDAO。

查询节点、首节点完整部署和完整网络配置指南将在后续补充。本手册已提供首矿工和 SourceDAO 操作，首节点从空白机器启动到对外提供 Seed 的完整流程仍需独立整理。

## 阅读和执行约定

所有节点命令都在安装节点的**同一个普通运维账号**下执行。需要主机权限的步骤会单独说明。`~` 表示这个账号的主目录；`/data/usdb` 只是可选的数据目录示例。

逐步执行命令，确认本步结果后再继续。命令输出中的 `Next actions` 是下一步建议；长时间没有新进度时，先查对应日志。

本文的“测试网”指 USDB 测试网络，其 Bitcoin 数据源仍是 **Bitcoin 主网**。运行普通节点不需要提供 Bitcoin 私钥。

## 文档版本

本批文档的命令接口及网络资料对照公开的 `usdb-testnet-v0-r25` 安装包，核对日期为 **2026-09-14**。具体可用范围、已知问题和验证程度集中维护在[版本页](networks/testnet.md#版本与验证范围)。之后的安装包可能改变提示和行为，应使用与其匹配的手册。

本文档提供用户操作指南；发布协调、构建和内部验收记录由[发布文档](../publish/README.md)维护。

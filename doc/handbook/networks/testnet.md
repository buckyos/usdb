以下身份取自 r25 的公开版本清单，由安装工具自动配置。保留这些信息是为了确认加入了正确网络，无需手工写入节点配置。

| 项目 | 值或获取方式 |
| --- | --- |
| 网络名称 | USDB testnet-v0 |
| 网络标识 | `usdb-testnet-v0` |
| Chain ID / Network ID | `202608250` |
| USDB P2P 默认端口 | `31303/TCP` 和 `31303/UDP` |
| Bitcoin 数据源 | Bitcoin mainnet |
| 网络性质 | 可重置的开发测试网；网络重置时按新网络通知重新部署 |
| Seed 地址 | 向当前网络运维方取得完整、可达的 `enode://…` 地址 |
| 浏览器、公共 RPC、水龙头 | 本页尚无已确认的服务地址；向网络运维方获取，不从节点私有端口推导 |

需要核对创世块时，r25 的 USDB genesis hash 为：

```text
0x12a1baed070d1521d791b73956a8b5cf1613fc9504636f215390c1f839992a23
```

相同 Chain ID 不足以证明两个节点属于同一条链；安装工具还会检查创世块和本地数据是否匹配。出现身份不匹配时，保留配置并查明版本，不修改 ID 或摘要绕过检查。

## 安装前需要取得的信息

1. 网络运维方指定的**完整安装版本号**及其 [GitHub Release 页面](https://github.com/buckyos/usdb/releases)，从页面复制 **Release-bound installer** 命令。确认该版本支持全新部署，并阅读已知问题。
2. 至少一个同网 Seed 的完整地址。地址应包括节点身份、可达 IP 或域名和 P2P 端口，不是 SSH 地址或 RPC URL。
3. 有网络重置或停链时使用的通知渠道，以及可以联系的网络运维人员。

不要用页面中的“Source code”压缩包代替节点安装器。选择指定版本，不使用会随时间改变的 `latest` 下载路径。

## 新旧启动方式

本批安装流程面向 **AssumeUTXO 发布包**。向导会显示原生启动提示，并由后台自动下载和验证所需文件。用户不填写快照 URL、起始高度或签名材料。

旧版 BH 数据库快照和从零同步部署的进度与恢复方法不同。若向导仍询问是否使用旧 BH snapshot，先确认选择的安装版本，不混用本批导入说明；旧版本操作按该版本随附说明处理。

从旧启动方式切换到 AssumeUTXO 涉及数据兼容变化，**不能直接当作一次普通版本升级**。需要单独的数据保留和重建安排，见[升级与恢复边界](../node/maintenance.md#升级节点)。

固定网络资料只在本页维护；公共服务地址也在确认可用后加入本页。网络重置时保留旧网络说明，并为新网络创建独立资料页。

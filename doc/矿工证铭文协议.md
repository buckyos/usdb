## v1 Mint 入口

所有 mint inscription 都必须包含：

```json
{
  "p": "usdb",
  "op": "mint",
  "v": 1
}
```

身份字段必须满足以下一种且仅一种形态：

- standard pass：包含合法 EVM `usdb_main`，不包含 Leader 绑定字段。
- fixed-Leader collab pass：包含合法 `leader_pass_id`，不包含 `usdb_main` 或其他 Leader 绑定字段。
- address-Leader collab pass：包含当前 BTC 网络上的合法 `leader_btc_addr`，不包含 `usdb_main` 或其他 Leader 绑定字段。

`prev` 是可选 inscription id 数组。其存在性、owner、状态、重复引用、继承折损和原子消费规则以 UIP-0001、UIP-0002、UIP-0003 为准。

实现、测试和 review 必须以对应 UIP 原文为唯一规范来源；本文不得作为独立兼容协议使用。
